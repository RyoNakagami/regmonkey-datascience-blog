# 記事の文体ルール

- 本文は「です・ます」調で書く
- 箇条書きは言い切り型（体言止め・「〜する」）で書く．「です・ます」は使わない
- 定義ブロック `::: {#def- .custom_problem ...}` の中は言い切り型（「〜とする」「〜という」「〜と呼ぶ」）で書く．「です・ます」は使わない
- 図（SVG）のキャプション `![...]` は1文で簡潔に書く．詳しい説明は本文に回す

# 見出しのルール

- 見出しは `##`（節）と `###`（小節）までを使う．`####` 以下は原則使わない
- `###` より細かい区切りが必要なときは，`[コンピューター内部の値を16進数で表すと都合が良い場面]{.mini-section}` のように `.mini-section` を使う
