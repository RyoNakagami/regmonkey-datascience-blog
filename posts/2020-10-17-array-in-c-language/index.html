ノートTL;DRs
  • 配列の定義: int data[10]; は int 型の箱を10個，メモリ上に連続して確保する．添字は 0 から 9 までで，data[10] は存在しない
  • & はアドレス演算子: scanf は読み込んだ値を書き込む「場所」を必要とするため，data[i] ではなく &data[i]（data[i] のアドレス）を渡す
  • %d と %f は書式指定子: %d は int を10進数で，%f は浮動小数点数を小数で読み書きする
  • sum / 10 ではなく sum / 10.0: int 同士の割り算は小数点以下が切り捨てられる．片方を 10.0 にすると浮動小数点数の割り算になる
  • 入力の検証: 整数以外（1.1 など）を入力すると scanf が読み込みに失敗し，初期化されていない配列の要素がそのまま足されて平均が壊れる．scanf の戻り値で成否を確認する
  • return 0 とシェルの真偽: main の戻り値は真偽値ではなく終了ステータスで，0 が成功・0 以外が失敗を表す．C の条件式（0 が偽）とシェルの if（終了ステータス 0 が真）で 0 の扱いが逆に見えるのはこのため（Appendix）

配列から平均値を求めるプログラム

キーボードから整数を10個読み込み，その平均値を表示するプログラムです．

average.c
#include <stdio.h>

int main(void)
{
  int data[10];
  int sum, i;
  float ave;

  sum = 0;

  for (i = 0; i < 10; i++)
  {
    scanf("%d", &data[i]);
    sum += data[i];
  }

  ave = sum / 10.0;
  printf("the average is %f\n", ave);

  return 0;
}

コンパイルして実行し，整数を10個入力すると平均値が表示されます．

% gcc -o average average.c
% echo "7 3 9 5 6 8 2 10 4 7" | ./average
the average is 6.100000

以下，まず プログラムの挙動 で全体の流れを図でつかみ，そのあとコードの要素を

  1. 配列の定義
  2. scanf に渡す &data[i]
  3. 書式指定子 %d / %f
  4. 平均の計算 sum / 10.0

の順にみていきます．最後に，整数以外を入力したときに何が起きるかを確認します．

プログラムの挙動

7 3 9 5 6 8 2 10 4 7 を入力したときの流れを図にすると次のとおりです．

  1. for ループで i を 0 から 9 まで変えながら，次の2つを10回くり返す
    • scanf("%d", &data[i]); で整数を1個読み，data[i] に格納する
    • sum += data[i]; で，格納した値を sum に足す（sum = sum + data[i]; と同じ）
  2. ループを抜けた時点で sum は10個の合計（この例では61）になっている
  3. ave = sum / 10.0; で平均（6.1）を求める
  4. printf で the average is 6.100000 と表示する

data[i] という書き方，&data[i] の &，%d / %f，10 ではなく 10.0 で割る理由は，以降の節で順に説明します．

配列の定義

Definition 1 配列（array）

  • 同じ型の値を，メモリ上に連続して並べたデータ構造
  • 型 配列名[要素数]; の形で定義する
  • 各要素には 配列名[添字] でアクセスする．添字は 0 から始まり，要素数 - 1 で終わる

int data[10]; は「int 型の値を入れる箱を10個並べ，その全体に data という名前を付ける」という定義です．

  • 各要素は data[0], data[1], …, data[9] で参照する
  • int が4バイトの環境では，data 全体で 4 × 10 = 40 バイトの連続した領域になる
  • 要素が連続して並ぶため，data[i] の場所は「先頭の場所 + 4 × i バイト」で計算できる

関数内で定義した配列は初期化されない

関数の中で定義した配列（int data[10];）の中身は，定義した時点では不定です． 以前そのメモリを使っていた値が残っているだけなので，何が入っているかは分かりません． このプログラムでは scanf が全要素に値を書き込むので問題になりませんが，読み込みに失敗すると不定な値がそのまま使われます（後述）． 最初から0で埋めておきたい場合は int data[10] = {0}; と書きます．

一方，sum は sum = 0; で明示的に0を入れています．これを忘れると，不定な値に足し算を重ねることになります．

&data[i] の & とは

ノートRULE: 書き込んでもらう変数には & を付ける
  • scanf の %d は「次の引数は int を書き込む場所（int *）」という約束です．
  • scanf("%d", &data[i]); と書けば，scanf は読み込んだ整数を data[i] の場所に書き込みます．

& はアドレス演算子で，変数の値ではなく，その変数がメモリ上のどこにあるか（アドレス）を取り出します．

式 意味 例（i = 2 のとき）
data[i] i 番目の要素の値 9
&data[i] i 番目の要素のアドレス 0x7ffd... のような番地

scanf に &data[i] を渡すのは，C言語の関数呼び出しが値渡しだからです．

  • 関数には引数の値のコピーが渡される．関数がコピーを書き換えても，呼び出し元の変数は変わらない
  • 呼び出し元の変数を関数に書き換えてもらうには，その変数のアドレスを渡す．関数はアドレスが指す場所に直接書き込める

& を付け忘れると？

scanf("%d", data[i]); と書くと，渡るのは data[i] の値（0 やゴミ値）です． しかし scanf は，渡されたものが値かアドレスかを区別できません． 実行時の scanf に届くのはビット列だけで，型の情報は付いていないため，書式指定子 %d を信じてその値を番地とみなし，そこへ書き込もうとします．

  • 書き込めない番地（0 番地など）なら，Segmentation fault で異常終了する
  • たまたま書き込める番地なら，無関係なメモリを壊したまま動き続ける

どちらになるかは決まっておらず，未定義動作です．

型の食い違いに気づけるのは，ソースコードの型を知っているコンパイル時のコンパイラだけです． gcc は次のような警告を出します．ただし警告なので，実行ファイルは作られてしまいます．

warning: format '%d' expects argument of type 'int *', but argument 2 has type 'int' [-Wformat=]
    5 |   scanf("%d", data[0]);
      |          ~^   ~~~~~~~
      |           |       |
      |           int *   int

%d, %f とは

scanf や printf の第1引数の中にある %d や %f は書式指定子（変換指定）です． 「ここにどの型の値を，どの形式で読み書きするか」を指定します．

書式指定子 scanf での対応 printf での対応 表示例
%d int へのポインタ（&data[i] など） int の値 61
%f float へのポインタ float または double の値 6.100000
%lf double へのポインタ double の値（%f と同じ） 6.100000
  • %d は整数を10進数として読み書きする
  • %f は浮動小数点数を小数点表記で出力する．桁数を指定しなければ小数点以下6桁になるため，6.1 は 6.100000 と表示される．%.2f とすると小数点以下2桁（6.10）になる
  • 書式文字列の % 以外の部分（the average is や改行 \n）はそのまま出力される

printf では float 型の ave を %f で表示できます． 可変長引数の関数に float を渡すと自動的に double に変換される（既定の実引数拡張）ため，printf の %f は実際には double を受け取っています． 一方 scanf に渡すのはポインタで，この変換は起きません．float には %f，double には %lf を使い分ける必要があります．

警告書式と型を一致させる

printf("%d", ave); のように書式指定子と実際の型が食い違うと未定義動作になり，でたらめな値が表示されることがあります． gcc -Wall でコンパイルすると，このような食い違いを警告してくれます．

sum / 10 ではなく sum / 10.0

C言語の割り算 / は，両辺の型によって動きが変わります．

  • 両辺が整数（int / int）: 整数の割り算になり，小数点以下は切り捨てられる
  • どちらかが浮動小数点数: もう一方も浮動小数点数に変換され，小数を含む割り算になる

sum は int 型なので，10 と 10.0 のどちらで割るかで結果が変わります．

式 型 結果（sum = 61） 表示
sum / 10 int / int 6 the average is 6.000000
sum / 10.0 int / double 6.1 the average is 6.100000

ave = sum / 10; と書くと，右辺が int の 6 になったあとで float の ave に代入されます． 代入先が float でも，切り捨てられた小数点以下は戻りません． 10.0 は double 型の定数なので，sum / 10.0 では sum が double に変換されてから割り算されます．

同じ結果は，キャスト（型変換）でも得られます．

ave = (float)sum / 10;   /* sum を float に変換してから割る */

(float)(sum / 10) と書くと，整数の割り算で切り捨てたあとに変換するため 6.0 になってしまいます．変換は割り算の前に行います．

整数以外を入力すると？

このプログラムに 1.1 を入力すると，次のようなでたらめな平均が表示されます（値は実行のたびに変わります）．

% ./average
1.1
the average is 70363096.000000

原因は，scanf の読み込み失敗と，配列が初期化されていないことの組み合わせです． 各回の scanf の戻り値（r）と data[i] を表示させると，何が起きているかが分かります． r は scanf が値を格納できた変数の個数で，r=1 が成功，r=0 が失敗です（詳しくは Appendix）．

i=0 r=1 data=1
i=1 r=0 data=0
i=2 r=0 data=0
...
i=6 r=0 data=537008864
i=7 r=0 data=30364
i=8 r=0 data=-1309804016
i=9 r=0 data=32766
  1. 1回目の scanf("%d", ...) は 1.1 のうち整数として読める 1 だけを読み，data[0] に 1 を格納する．.1 は入力に残る
  2. 2回目以降の scanf は，残った . を整数として読めずに失敗する．失敗した文字は読み捨てられないので，残り9回とも同じ . で失敗する
  3. 失敗した回は data[i] に何も書き込まれず，不定な値（前に使われていたメモリの中身）が残ったまま sum に足される

scanf の戻り値を確認すれば，読み込みに失敗した時点で処理を止められます． %d を1つ指定した呼び出しでは，成功したときの戻り値は 1 なので，1 以外なら失敗として扱います．

average.c（入力チェック付き）
#include <stdio.h>

int main(void)
{
  int data[10];
  int sum, i;
  float ave;

  sum = 0;

  for (i = 0; i < 10; i++)
  {
    if (scanf("%d", &data[i]) != 1)
    {
      fprintf(stderr, "error: %d 個目の入力が整数ではありません\n", i + 1);
      return 1;
    }
    sum += data[i];
  }

  ave = sum / 10.0;
  printf("the average is %f\n", ave);

  return 0;
}
% ./average
1.1
error: 2 個目の入力が整数ではありません

1.1 の 1 は1個目の整数として受け付けられ，.1 で2個目の読み込みに失敗したことが分かります．

Appendix: scanf の戻り値

scanf は，値を格納できた変数の個数を戻り値として返します． 本文のログの r の列がこの戻り値です．

戻り値 意味（scanf("%d", &data[i]) の場合）
1 1個の変数に格納できた → 成功
0 1個も格納できなかった → 失敗（. のように整数として読めない文字があった）
EOF 何も読まないうちに入力が終わった．<stdio.h> で負の値（glibc では -1）と定義されている

1.1 を入力した例では，1回目は 1 を読めたので r=1，2回目以降は . で止まるので r=0 になります．

ノートログを出したデバッグ用のコード

本文のプログラムの for ループを次のように書き換え，戻り値を r に入れて毎回表示しています．

int r;

for (i = 0; i < 10; i++)
{
  r = scanf("%d", &data[i]);
  printf("i=%d r=%d data=%d\n", i, r, data[i]);
  sum += data[i];
}

r=0 の回の data[i] は初期化されていない値を読んでいるため，表示される値は実行のたびに変わります．

書式指定子が複数あるとき

戻り値が「成功か失敗か」ではなく「個数」なのは，1回の呼び出しで複数の値を読めるからです． scanf("%d %d", &a, &b); に次の入力を与えると，戻り値は格納できた個数に応じて変わります．

入力 戻り値 a b 何が起きたか
3 4 2 3 4 2個とも格納できた
3 x 1 3 変化なし a だけ格納し，x で止まった
x 4 0 変化なし 変化なし 最初の x で止まった
（空） EOF 変化なし 変化なし 入力が何もなかった

「どこまで読めたか」が分かるように個数を返し，途中で失敗した場合も区別できるようにしています． 成功したときの戻り値は，書式指定子で指定した変数の個数と一致します．

if (scanf(...)) と書いてはいけない

「0 なら失敗」なので，C の真偽（0 が偽）を使って次のように書きたくなります．

if (scanf("%d", &data[i]))   /* NG */
{
  sum += data[i];
}

しかし EOF は負の値で，C の条件式では 0 以外はすべて真です． 入力が途中で終わったとき（EOF）も成功として扱われ，未初期化の data[i] を足してしまいます． 本文のように != 1（指定した個数と一致しないか）で判定します．

if (scanf("%d", &data[i]) != 1)   /* OK: 0 も EOF も失敗として扱う */
